# MediCare HMS — Hospital Management System
একটি আধুনিক, হালকা ও দ্রুতগতির হসপিটাল ম্যানেজমেন্ট সিস্টেম (HMS) ওয়েব অ্যাপ্লিকেশন। হাসপাতালের ওষুধের স্টক (+/- সমন্বয়), রোগী ভর্তি ও ছাড়পত্র (রিলিজ), এবং সিজারিয়ান ও স্বাভাবিক প্রসবের সকল তথ্য সহজে পরিচালনার জন্য এটি ডিজাইন করা হয়েছে।

---

## 🌟 মূল ফিচারসমূহ (Core Features)

### ১. সাধারণ লাইভ ভিউ (Public Display Board) — `/#public`
- সাধারণ দর্শনার্থী ও রোগীদের জন্য সার্বক্ষণিক উন্মুক্ত লাইভ ডিসপ্লে।
- **ওষুধের স্টক স্ট্যাটাস ও জরুরি সতর্কতা:** যেকোনো ওষুধ কমে গেলে বা স্টক শেষ হলে তাৎক্ষণিক অ্যালার্ট ব্যানার।
- **ভর্তি ও রিলিজ রোগী ট্র্যাকিং:** বর্তমানে কতজন রোগী চিকিৎসাধীন এবং কে কে সুস্থ হয়ে বাড়ি ফিরেছেন (রিলিজ প্রাপ্ত) তাদের তথ্য।
- **প্রসূতি ডেলিভারি তথ্য:** সফল সিজারিয়ান ও স্বাভাবিক প্রসবের স্বচ্ছ পরিসংখ্যান।
- সম্মুখ পেজে কোনো পাসওয়ার্ড বা লগইন সংক্রান্ত তথ্য প্রদর্শন করা হয় না (১০০% সিকিউর)।

### ২. স্টাফ ১ পোর্টাল (Staff 1 Portal) — `/#staff`
- একক পাসকোড (`1234`) দ্বারা সুরক্ষিত।
- **ওষুধের প্লাস-মাইনাস (`+` / `-`):** ওষুধের তালিকা থেকে সরাসরি ১ ক্লিকে স্টক বাড়ানো বা কমানো।
- নতুন বাণিজ্যিক বা জেনেরিক ওষুধের নাম তালিকাভুক্ত করা ও ডিলিট করা।
- **রোগী ভর্তি ও ১-ক্লিক ছাড়পত্র:** নতুন রোগী ভর্তি করা এবং ছাড়পত্র দেওয়ার সাথে সাথে রিলিজ প্রাপ্ত তালিকায় স্থানান্তরিত হওয়া।
- সিজারিয়ান ও নরমাল প্রসবের বিবরণ সংরক্ষণ (মা ও নবজাতকের ওজন, লিঙ্গ, ডাক্তার, স্বাস্থ্যাবস্থা ইত্যাদি)।
- সম্পূর্ণ বিজ্ঞাপন ও খরচ (Expense) মুক্ত ইন্টারফেস।

### ৩. সুপার এডমিন মাস্টার প্যানেল (Super Admin Panel) — `/#admin`
- সম্পূর্ণ সিস্টেম পরিচালনার সর্বোচ্চ নিয়ন্ত্রণ (Full Control)।
- জিমেইল ও পাসওয়ার্ড দ্বারা সুরক্ষিত।
- ওষুধ, রোগী ও ডেলিভারি রেকর্ডের পূর্ণাঙ্গ মাস্টার ম্যানেজমেন্ট।
- **অডিট ট্রেইল (Audit Logs):** কে কখন কোন ওষুধ যোগ বা স্টক পরিবর্তন করেছে তার রিয়েল-টাইম লগ।
- **ব্যাকআপ ও রিস্টোর:** ১-ক্লিকে সম্পূর্ণ ডাটাবেজ JSON ফাইলে এক্সপোর্ট ও ব্যাকআপ থেকে রিস্টোর করার সুবিধা।

## 🚀 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

১. রিপোজিটরি ক্লোন করুন:
```bash
git clone https://github.com/hasanvaiya/hospital.git
cd hospital
```

২. ডিপেনডেন্সি ইনস্টল করুন:
```bash
npm install
```

৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে ওপেন করুন: `http://localhost:5173/`
